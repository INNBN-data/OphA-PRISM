# Release checklist

## Public source release

- [x] Source, configuration, license, and citation metadata included.
- [x] Clinical records and fitted objects excluded.
- [x] Reported summaries distinguished from generated outputs.
- [x] Reference-method differences documented.
- [x] Directory structure and checksum manifest preserved.
- [x] Verification scope recorded in SOFTWARE_TEST_REPORT.md.

## Empirical reproduction

- [ ] Verify the complete dictionary, ordered features, and source hashes.
- [ ] Reconcile historical imputation, partitions, calibration, and repeated prediction sets.
- [ ] Execute model-library checks in the declared server environment.
- [ ] Verify bootstrap, permutation, agreement, and sample-size outputs.
- [ ] Recompute manuscript metrics and uncertainty from the saved predictions.
- [ ] Compose the empirical main-text figures from verified source tables.
